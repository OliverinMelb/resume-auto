# 牛客岗位调研数据源

## 这次增加了什么

牛客以独立的 `job_sources/nowcoder/` 数据源接入现有 FastAPI 服务，不修改
`web_script.js`，也不替换或删除 Boss 直聘功能。

这条链路完成：

- 默认通过结构化职位分类和城市执行匿名分页搜索并读取公开详情；
- 在用户明确选择精确筛选时，使用独立、可见的 Playwright Chrome；
- 采集职位列表，读取牛客公开详情，并标准化为统一岗位结构；
- 将岗位正文复用现有 JD 评分器评分，但不以分数过滤采集结果；
- 支持不写数据库的快速预览；
- 支持带检查点、停止和恢复能力的完整调研；
- 保留牛客原文链接及聚合岗位的官网申请链接；
- 独立分页读取网申日历中的招聘项目和官网入口，不将招聘项目伪装成岗位；
- 遇到登录、验证、HTTP 403 或 429 时暂停或报错，不尝试绕过。

本功能不会自动投递、自动联系招聘者、破解接口签名、绕过验证码或访问权限。

## 目录和数据流

```text
job_sources/contracts.py             最小统一岗位与查询契约
job_sources/evaluation.py            复用现有 JD 评分器
job_sources/router.py                数据源聚合路由
job_sources/nowcoder/anonymous.py    匿名筛选元数据与分页搜索适配器
job_sources/nowcoder/campaigns.py    网申日历招聘项目分页适配器
job_sources/nowcoder/browser.py      可见 Chrome 搜索与翻页
job_sources/nowcoder/source.py       公开详情读取、解析和标准化
job_sources/nowcoder/tasks.py        快速/调研任务、停止与恢复
job_sources/nowcoder/checkpoints.py  原子化任务检查点
job_sources/nowcoder/research.py     写入 Resume Agent 候选项目
job_sources/nowcoder/router.py       本地 API
job_sources/nowcoder/ui.html         本地操作页面
test_nowcoder_source.py              单元与路由测试
```

```text
本地页面填写查询
→ 选择“免登录自动筛选”或“浏览器精确筛选”
→ 匿名筛选：关键词直接作为 search 查询，可选 careerJob 和 city 后按 page 翻页
→ 浏览器筛选：可见 Chrome 应用关键词、城市、毕业年份和排序
→ 标准化岗位并复用现有 JD 评分
→ 页面展示
→ 完整调研模式才写入 Resume Agent
```

网申日历是另一条独立链路：

```text
公司名称和城市
→ 牛客网申日历分页接口
→ 招聘项目（公司、批次、日期、城市、岗位类别）
→ 展示牛客日程、官网投递和信息来源链接
```

## 数据获取方式

### 免登录自动筛选（默认）

- 不启动 Chrome，不要求登录；
- 本地 UI 从牛客匿名接口加载职位分类树和 10 个热门招聘城市，不展开全球城市树；
- 关键词直接传给匿名职位广场接口的 `query` 字段，可搜索职位名称、公司、标签和
  JD 内容；`AI-Agent`、`软件开发` 等词不需要先匹配职位分类；
- 职位分类是可选的附加过滤器；手动选择后会与关键词同时生效，不选择则不限制分类；
- 后端生成并保存规范化筛选快照，其中 `search` 是关键词，`careerJob` 是可选数字
  分类 ID，`city` 使用标准 UTF-8 URL 编码；
- 列表通过匿名搜索接口按 `page` 翻页，并按岗位 ID 去重；
- 快速预览最多读取 30 条候选、3 页；
- 完整调研按牛客返回的总页数推进，每批仍受 100 页上限约束；
- 城市、招聘频道和毕业年份仍会按公开详情中的证据复核；
- 关键词用于上游搜索和结果排序；手动选择时再叠加所选 `careerJob`；
- “最新”只按公开详情提供的发布时间排序；
- 公开详情读取失败时记录失败，不会隐式启动浏览器兜底。

例如，上海 Java 后端校招筛选 URL：

```text
https://www.nowcoder.com/jobs/school/jobs?search=Java&city=上海&careerJob=11002
```

当前匿名接口属于牛客页面内部接口，不是对外稳定 API。若出现 HTTP 403/429、验证或
响应结构变化，匿名任务会停止；需要时由用户显式选择浏览器模式，不会自动打开
Chrome。

### 网申日历（招聘项目）

- 网申日历使用独立的 `/job-sources/nowcoder/campaigns` 本地接口；
- 每次读取一页并保留牛客返回的当前页、总页数和总项目数，页面支持上一页和下一页；
- 公司名称和职位类别是可选搜索条件，城市沿用页面上方的热门城市选择；
- 职位类别使用牛客网申日历自己的第二级分类编码，直接缩小上游分页结果；
- 每个项目包含公司、招聘批次、城市、岗位类别、网申日期和状态；
- 官网申请地址只作为链接展示，采集过程不会访问或解析公司官网；
- 外链只接受没有用户名和密码的 HTTP(S) URL，并使用独立新窗口打开；
- 招聘项目不是具体岗位，不参与 JD 评分，也不写入 Resume Agent 的岗位表。
- 查询结果可以收起和重新展开，筛选控件始终保留在页面上。

### 浏览器精确筛选

- 使用牛客页面自己的关键词与筛选控件；
- 可以翻页，并在完整调研中保存检查点；
- 可能触发牛客正常登录或人工验证；
- 登录或验证出现时任务暂停，完成后可在本地 UI 点击继续；
- 公开 HTTP 详情失败时才允许使用同一可见页面读取详情。

牛客使用仓库专用的 Chrome 用户目录，不复用日常 Chrome 配置：

```text
.runtime/nowcoder/browser-profile/
```

可恢复任务保存在：

```text
.runtime/nowcoder/tasks/
```

整个 `.runtime/` 已被 Git 忽略，Cookie、登录状态和本地检查点不会进入提交。

## 安装与启动

环境要求：

- Python 3.11；
- `uv`；
- 本机已安装 Google Chrome；
- 能正常访问牛客公开职位页面。

在仓库根目录执行：

```powershell
uv sync
uv run python main.py
```

服务默认地址：

```text
http://127.0.0.1:8010
```

牛客操作页面：

```text
http://127.0.0.1:8010/job-sources/nowcoder/ui
```

FastAPI 接口文档：

```text
http://127.0.0.1:8010/docs
```

如果 8010 端口已经运行旧进程，需要先正常停止旧进程，再重新启动，确保加载的是
当前分支代码。

## 如何匿名读取“上海 Java 后端校招”

1. 打开本地牛客操作页面。
2. 数据获取方式保留“免登录自动筛选”。
3. 渠道选择“校招”。
4. 职位分类保留“不限职位分类”，或按需手动选择具体职位分类缩小范围。
5. 城市选择“上海”。
6. 关键词填写岗位、公司或技术方向，例如“前端”“AI-Agent”或“软件开发”。
7. 运行模式选择“快速预览”，点击开始。

浏览器模式由可见 Chrome 执行牛客站内交互。免登录模式直接调用当前职位广场使用的
匿名关键词搜索，并保留站内返回的相关结果，不要求职位标题必须精确包含关键词。

## 快速预览与完整调研

### 快速预览

- 免登录和浏览器模式最多获取 30 条、读取 3 页；
- 展示标准化岗位和候选人画像匹配分；
- 不写入 `resume_agent.db`；
- 适合检查筛选条件和页面兼容性。

### 完整调研

- 每批最多推进 100 页；
- 保存列表、详情、失败项和当前进度；
- 可以停止，再显式恢复；
- 服务重启后，未完成任务恢复为暂停状态，不会自行继续；
- 必须新建或明确选择一个 Resume Agent 候选项目；
- 按 `nowcoder + source_job_id` 写入和去重。

实习岗位的薪资原文仍保留在岗位证据和页面展示中，但写入 Resume Agent 时通用薪资
字段为空，因此不会混入普通岗位的市场平均薪资统计。

## 状态说明

| 状态 | 含义 | 处理方式 |
|---|---|---|
| `running` | 正在读取列表或详情 | 等待任务推进 |
| `completed` | 当前范围已读取完成 | 检查结果和失败数 |
| `paused` | 用户停止或重启后等待恢复 | 点击继续 |
| `waiting_for_login` | 牛客要求正常登录 | 在独立 Chrome 登录后点击继续 |
| `verification_required` | 牛客显示人工验证 | 在独立 Chrome 完成验证后点击继续 |
| `failed` | 页面结构、网络或数据校验失败 | 查看错误信息，修复后再恢复或新建任务 |

HTTP 403、429 和明显的访问限制不会转为浏览器绕过，任务会保留已有结果并停止继续
请求。浏览器搜索后异步出现的登录弹窗也会归类为 `waiting_for_login`，不会误报为
页面结构变化。

## 数据与兼容边界

- Boss 直聘原有浏览器脚本、评分接口和自动投递行为保持不变；
- 快速预览不会修改数据库；
- 完整调研只写入用户明确选择的本地 Resume Agent 数据库；
- 不包含数据库迁移；
- 不提交 `.env`、Cookie、Token、登录状态或抓取结果；
- 对 Moka、北森等牛客聚合岗位，只保存牛客公开摘要及官网申请链接，不继续抓取外部
  ATS；
- 当前共享查询契约偏向牛客需要，后续接入其他数据源前应先做最小兼容评审，不应
  直接扩成重量级框架。

## 本地验证

运行全部 Python 测试：

```powershell
uv run python -m unittest discover -p "test_*.py"
```

只运行牛客测试：

```powershell
uv run python -m unittest test_nowcoder_source.py
```

检查锁文件：

```powershell
uv lock --check
```

浏览器验收应至少覆盖：

1. 匿名模式加载职位分类和城市，不启动 Chrome；
2. `AI-Agent`、`软件开发` 等自由文本生成正确的 `search`、`city` 筛选快照；
3. 手动选择职位分类时，`careerJob` 与 `search` 同时生效；
4. 匿名快速预览能够读取第 2 页且不超过 30 条；
5. 旧任务中的合法 `filtered_url` 仍可恢复；
6. 浏览器模式覆盖关键词、城市、毕业年份和“最新”排序；
7. 独立 Chrome 正常登录后继续；
8. 完整调研停止、服务重启和显式恢复；
9. 牛客原文链接与官网申请链接；
10. 快速预览前后数据库文件大小和修改时间不变。

## 回滚

本功能集中在 `nowcoder` 分支。若尚未合并，直接切回原分支即可停用：

```powershell
git switch codex/boss-dom-resilience
```

若未来已经通过正常 Git 流程合并，应使用 `git revert` 撤销对应提交，不要使用
`git reset --hard` 覆盖其他人的工作。

`.runtime/nowcoder/` 只包含可重新生成的本地浏览器状态和任务检查点，不属于 Git
提交。是否清理该目录由用户自行决定，回滚代码不需要删除它。
